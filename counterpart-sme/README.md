# Counterpart SME

Counterpart for growing businesses: the same English law drafting tool, with the twenty agreements a business uses most, a guided start, documents saved to your account, electronic signing and renewal reminders.

## Run it

```bash
npm run check   # must print ALL CLEAN
npm run build   # writes dist/index.html (standalone) and dist/artifact.html (Claude artifact)
npm run serve   # then open http://localhost:8000
```

## What it does

- Everything in Counterpart: the drafting screen with ranked options and explanations, deal details, Word export, Review a draft with redlines, the clause library, guidance and the playbook.
- **Get started:** a short guided start that picks the agreement, your side and a starting position for every negotiable clause from your priorities and negotiating position.
- **Your documents:** every draft is saved, to your Claude account when opened in Claude, otherwise in the browser.
- **Signing:** prepare a document to lock it and fingerprint its text, sign by drawing or typing, and have the other party sign with a code. Signed Word copies carry an electronic signature certificate. Deeds are signed on paper and recorded.
- **Key dates:** renewal and notice dates on the home page, with calendar reminders.

Template documents and general information only. Not legal advice.
